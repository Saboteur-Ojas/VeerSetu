# 🛡️ VeerSetu – Frontend

> A privacy-first digital wellbeing support interface designed to provide a simple, accessible, and stress-free experience for personnel.

## 📌 Overview

**VeerSetu** is a digital personnel wellbeing and support platform designed with a strong focus on **privacy, accessibility, and simplicity**.

This repository contains the **frontend implementation** of the VeerSetu application. The interface is designed to provide a calm and intuitive experience while allowing users to access essential wellbeing and support features without exposing sensitive personal information unnecessarily.

The frontend follows a **clean, modern, and minimal UI philosophy**, ensuring that the application remains easy to use even in potentially stressful situations.

## 🎨 UI/UX Philosophy

The VeerSetu frontend has been designed around the following principles:

* **Minimal Cognitive Load** – Avoid unnecessary information and complex visualizations.
* **Privacy First** – Sensitive information should feel protected and controlled.
* **Stress-Free Interface** – Calm layouts, readable typography, and simple interactions.
* **Accessibility** – Easy navigation and clear interface elements.
* **Responsive Design** – Optimized for different device sizes.

> ⚠️ The application intentionally avoids displaying complex welfare trajectories, stress graphs, or potentially anxiety-inducing performance patterns directly to personnel.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm or yarn
* Expo Go application (for mobile testing)

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd veersetu-frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

You can then run the application using:

* 📱 Expo Go on Android or iOS
* 🤖 Android Emulator
* 🍎 iOS Simulator
